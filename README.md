# 💳 Credit Card Fraud Detection

A machine learning project that identifies potentially fraudulent credit card transactions using a **Tuned Random Forest Classifier**. The project handles the highly imbalanced transaction dataset and evaluates the model using multiple performance metrics.

### 📊 Model Performance

| Metric    |      Score |
| --------- | ---------: |
| Accuracy  | **99.94%** |
| Precision | **84.04%** |
| Recall    | **80.61%** |
| F1 Score  | **82.29%** |

### 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest
* Joblib
* Streamlit

### 🚀 Features

* Classifies transactions as **Legitimate** or **Fraudulent**
* Uses a tuned Random Forest model
* Displays prediction probability
* Provides a Streamlit web interface
* Saved model and scaler for future predictions
